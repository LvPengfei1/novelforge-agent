# 常用写作提示词

这里收集了日常写作中最常用的启动指令，复制使用即可。`【】` 中的内容按实际情况替换。

---

## 写正文

写新章节。先读取资料再动笔：

```text
写第【X】章。先读取资料再动笔。

读取顺序：
1. llm-wiki/wiki/index.md
2. llm-wiki/wiki/book-spine.md（当前进度）
3. llm-wiki/wiki/outline.md（剧情总纲，确认本章在哪个章节组、必须推进什么）
4. 小说工程/03_剧情/章节/ch【X-1】-spine.md（上一章龙骨，确认开章状态）
5. llm-wiki/wiki/character-states.md（人物当前状态）
6. llm-wiki/wiki/foreshadowing-ledger.md（伏笔当前状态）

读完资料后，先建立 ch【X】章节龙骨草案给我确认，确认后再写正文。写完后按规则同步更新所有关联文件。
```

续写/改写当前章节：

```text
根据最新章节龙骨，继续写第【X】章正文。保持视角、情绪和节奏连贯。
```

```text
重写第【X】章的【某段内容】，改为【具体要求】。改完后同步章节龙骨和关联文件。
```

## 写龙骨

只生成章节龙骨，不写正文：

```text
请根据当前 llm-wiki，生成第【X】章的章节龙骨草案。必须包含章节功能、开章状态、本章目标、核心推进、结尾变化、后续约束和待回收问题。不要写正文。
```

汇总写作前上下文：

```text
请根据 book-spine.md、outline.md 和当前/相邻章节龙骨，汇总第【X】章所在章节组的功能、主线推进、支线咬合、必须承接的状态和本章不应提前揭示的内容。不要写正文。
```

## 查设定

查人物：

```text
请查询【人物名】的当前状态、核心动机、关系变化、已发生关键事件和禁止违背的写法。
```

查地点：

```text
请查询【地点名】的功能、氛围、相关人物、已发生事件和当前限制。
```

查场景相关设定：

```text
请汇总与【章节/场景名称】相关的人物、地点、组织、规则、伏笔和未解决冲突。只列已确立事实，标出 wiki 缺失、矛盾或需要回查的条目。
```

查证据等级：

```text
请检查【设定/人物/规则/研究结论】的证据等级：已确立、来源依据、推断待确认还是废弃旧版。列出依据文件和需要用户确认的内容。
```

查伏笔：

```text
请列出当前所有未回收伏笔，按与第【X】章的相关度排序，并说明哪些不能提前揭示。
```

## 做研究

写前补充现实资料：

```text
第【X】章涉及【现实行业/历史/法律/技术/平台规则】。请先补充写前研究，优先读取原始资料/和已摄入 wiki；资料不足时再查找可靠来源。输出关键结论、来源、证据等级和写作限制，不写正文。
```

---

## 检查连续性

章节级检查：

```text
请检查第【X】章的章节龙骨是否与 book-spine、timeline、character-states、relationship-states、foreshadowing-ledger 和 contradiction-flags 一致。列出矛盾、缺失同步项和建议修正。
```

大纲级检查：

```text
请检查 outline.md 是否准确串联当前章节组：章节组功能、主线推进、支线状态和后续规划是否与 book-spine、当前/相邻章节龙骨、timeline、foreshadowing 一致。列出需要修正的条目。
```

场景级检查：

```text
请检查【章节/场景名称】涉及的人物状态、时间线、地点、道具、信息差和伏笔是否存在矛盾。输出冲突条目和建议处理方式。
```

---

## 章后同步

写完正文后一键同步：

```text
第【X】章初稿已完成。请按顺序执行：1）更新章节龙骨；2）检查是否需要更新 outline.md；3）执行节点缺口检查（人物、地点、组织等是否达到建卡门槛）；4）同步所有关联文件。列出每项的处理结果。
```

原创性检查：

```text
请依据 AIGC_DETECTION_PRINCIPLES.md 对第【X】章正文执行原创性与文本质量检查，列出问题位置和影响，修改正文并复查。
```

## 导入资料

摄入原始资料：

```text
请将原始资料/里的【资料名】摄入到 llm-wiki。提取所有人物、地点、组织、规则、主线和伏笔，更新对应 wiki 页面和索引。
```

口述设定整理：

```text
我来口述【人物/世界观】设定，帮我整理到 llm-wiki 并更新关联文件。
```

---

## 健康检查

```text
请对当前 llm-wiki 执行健康检查：页面之间是否矛盾、旧设定是否被取代、孤立页面、缺失交叉引用、需要用户确认的空白。输出检查结果。
```

```text
请找出同名、近义或可能重复的人物、地点、组织、规则、物品页面，给出合并建议，不要直接合并。
```
