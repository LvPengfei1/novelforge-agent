# AIGC 检测与原创性质量控制

本文档用于说明本项目如何理解 AIGC 文本检测，并把相关风险转化为小说写作质量要求。

## 定位

本项目不建立“绕过检测器”的规则，不提供针对具体检测工具的规避步骤，也不承诺任何文本能通过或避开 AIGC 检测。

本项目采用的口径是：通过更强的原创性、人物声音、场景细节、节奏变化和人工审校记录，减少模板化 AI 文本痕迹，让正文更像稳定、可追踪、可修改的小说创作成果。

## 常见检测手段

当前 AIGC 检测大致包括以下几类：

1. 统计与语言特征  
   检查文本可预测性、句式分布、词汇多样性、段落节奏、重复模式、风格稳定性等。早期检测器常使用 perplexity、burstiness、stylometry 等指标或衍生特征。

2. 机器学习分类器  
   使用人工文本和 AI 文本训练分类模型，判断某段文本更接近哪一类。此类方法依赖训练数据、语言、文本长度和文本类型，跨领域可靠性有限。

3. 水印与生成端信号  
   某些生成系统可能在输出中嵌入可检测信号，或通过平台侧记录识别生成来源。该方向依赖生成端配合，并不适用于所有模型和所有文本。

4. 来源凭证与元数据  
   C2PA / Content Credentials 等方案通过加密绑定的来源凭证记录内容来源、修改历史和是否使用 AI。它偏向“来源证明”，不是单纯通过文本风格猜测作者。

5. 人工复核与证据链  
   检测结果通常需要结合草稿、版本记录、创作过程、引用来源、人工说明和上下文判断。单一分数不应作为唯一结论。

## 已知局限

- 检测器可能误判人工文本，也可能漏判 AI 文本。
- 短文本、非英语文本、诗歌、剧本、代码、格式化文本和高度模板化文本更难可靠判断。
- 文本经过人工修改、翻译、混合写作或风格迁移后，检测可靠性会进一步下降。
- 不同检测器使用不同模型与阈值，结果可能互相冲突。
- 检测分数不是文学质量分数，也不是版权、原创性或合规性的充分证据。

## 项目写作要求

写作、续写、改写和润色时，智能体必须优先满足以下要求：

- 从章节龙骨、人物状态、场景冲突和伏笔账本出发写正文，不用通用模板填充内容。
- 保持人物声音差异，避免所有角色使用同一种句式、词汇和解释方式。
- 增加来自剧情现场的具体细节：动作、物件、空间、感官、选择、代价和后果。
- 让段落与句式随场景变化，不追求机械整齐。
- 避免空泛套话、过度总结、主题直白说教和反复使用同类连接词。
- 改写必须围绕叙事功能重构，不做同义词替换式洗稿。
- 使用参考资料时必须消化为小说场景逻辑，不能拼贴原文表达。
- 重要章节应保留创作过程记录：章节龙骨、正文版本、修改原因、人工确认和同步日志。

## 审查清单

章节完成前执行“原创性与 AIGC 痕迹质量检查”：

- [ ] 本章是否有明确的场景目标、阻力和变化。
- [ ] 人物语言是否符合其身份、关系、经历和当前情绪。
- [ ] 是否存在连续多段结构过于相似的问题。
- [ ] 是否存在大量抽象形容词、泛化连接词或总结式表达。
- [ ] 是否存在为了交代设定而让角色说出不自然信息的问题。
- [ ] 是否存在参考资料拼贴、段落洗稿或同义替换式改写。
- [ ] 是否能从章节龙骨、人物状态、伏笔账本和日志追溯本章创作依据。
