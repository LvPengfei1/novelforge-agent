# NovelForge-Agent 1.0.2 Release Notes

发布日期：2026-05-28

## 摘要

1.0.2 版本重点解决“正式写小说后，正文和私有设定会污染框架仓库提交”的问题。框架仓库现在只维护智能体规则、说明文档和空项目模板；真实小说项目应复制模板到本地实例目录或仓库外部目录中创作。

## 主要变化

- 新增 `模板/小说项目/`，集中保存可复制的空小说项目骨架。
- 新增 `作品/`，作为本地小说实例目录；默认不提交到 Git。
- 新增 `.gitignore`，忽略 `作品/` 下的实际小说项目，并防止误建的根目录 `原始资料/`、`小说工程/`、`llm-wiki/` 进入框架仓库。
- 新增 `docs/project-instance-guide.md`，说明框架仓库与小说实例如何分离。
- 更新 `AGENTS.md` / `Claude.md`，明确真实小说应在 `作品/<novel-slug>/` 或仓库外部目录中创作。
- 更新 README、使用手册和方案文档，改为平台无关的相对路径说明，不再写特定系统命令。
- 精简重复规则说明，保留 `AGENTS.md` / `Claude.md` 作为强规则源头，其他文档减少重复展开。

## 迁移说明

- 原先位于仓库根目录的空骨架 `原始资料/`、`小说工程/`、`llm-wiki/` 已移动到 `模板/小说项目/`。
- 新建小说时，将 `模板/小说项目/` 复制为 `作品/<novel-slug>/`，并把根目录的 `AGENTS.md`、`Claude.md`、`AIGC_DETECTION_PRINCIPLES.md` 放入该小说实例根目录。
- 已经在旧根目录结构中写作的项目，应迁移到 `作品/<novel-slug>/` 或仓库外部目录，再继续创作。
- 如果某本小说也需要版本管理，应在小说实例目录内建立独立 Git 仓库。

## 发布内容

- 提交范围：框架规则、说明文档、发布说明、模板目录和 Git 忽略规则。
- 不包含具体小说正文。
- 不包含运行时代码或依赖变更。
