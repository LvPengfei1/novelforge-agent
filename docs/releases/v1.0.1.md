# NovelForge-Agent 1.0.1 Release Notes

发布日期：2026-05-28

> 说明：本文件记录 1.0.1 当时的结构。后续 Unreleased 已将空小说项目骨架整体移动到 `templates/novel-project/`，真实小说实例应放在 `projects/<novel-slug>/` 或仓库外部目录。

## 摘要

1.0.1 版本重点完善 `llm-wiki` 的小说知识库结构：把章节龙骨从最终 wiki 图谱层中拆出并归入 `novel/03_plot/chapters/`，在 wiki 中只保留总体大纲入口；同时建立人物、地点、组织、规则、物品、场景、伏笔等分类主节点，让长篇小说设定更适合检索、维护和防矛盾。

## 主要变化

- 新增 `llm-wiki/wiki/outline.md`，作为全书龙骨与单章龙骨之间的总体大纲，用来关联 `novel/03_plot/chapters/` 中的章节龙骨。
- 将章节龙骨迁移到 `novel/03_plot/chapters/`。
- 新增 `llm-wiki/templates/`，统一存放人物卡、地点卡、组织卡、规则卡、物品卡、场景卡和伏笔节点模板。
- 新增 `llm-wiki/wiki/characters/`、`locations/`、`organizations/`、`rules/`、`items/`、`scenes/`、`foreshadowing/` 分类目录。
- 将 `llm-wiki/wiki/index.md` 调整为顶层索引，只关联分类主节点和少量全局入口。
- 将 `llm-wiki` 内部多个 `README.md` 主节点改为中文语义文件名，避免知识图谱中出现大量重名 README 节点。
- 增加节点建卡门槛，明确哪些人物、地点、组织、规则、物品、重要场景和伏笔必须独立成页。
- 增加章节字数验收规则：默认约 3000 字，普通章节正文字数范围为 2500-4000 字。
- 同步更新 `AGENTS.md`、`Claude.md`、`README.md`、`README.en.md`、`docs/usage-guide.md` 和 `docs/novel-agent-plan.md`。

## 迁移说明

- 旧路径 `llm-wiki/wiki/chapters/` 和 `llm-wiki/process/chapters/` 不再作为章节龙骨目录，使用 `novel/03_plot/chapters/`。
- 模板不进入最终 wiki 图谱，统一放在 `llm-wiki/templates/`。
- 根目录 `README.md` 保持仓库入口用途。
- `raw/` 和 `novel/` 下现有 README 文件继续保留。
- 已有项目可以逐步迁移，只要 `llm-wiki/wiki/index.md` 和分类主节点能清楚指向实际资料即可。
