# NovelForge-Agent 1.0.3 Release Notes

发布日期：2026-06-22

## 摘要

1.0.3 版本重点优化“写作流程与上下文隔离”。框架继续用工程化方式管理设定、流程、连续性和验证，但正文生成层只接收当前小说项目派生出的故事上下文，避免把同步表、日志、内部流程和工程词带进小说正文。

## 主要变化

- 新增“内容执行标准”：写作、续写、改写或审查前，先从当前项目简报、全书龙骨、总体大纲、章节龙骨、人物状态、关系状态和伏笔账本中派生本次写作标准。
- 新增“内容上下文胶囊”：正文生成只接收已发生剧情、本章开场状态、出场人物状态、人物动机、本章核心冲突、本章必须推进、本章结尾变化和项目文风。
- 新增正文纯净规则：正文文件只包含章节标题和正文；章末变更记录、同步检查、修改原因和审查记录应放入章节龙骨、连续性资料或日志。
- 新增工程词转译规则：阶段、锚点、接口、后台、控制台、同步、检测、节点等工程层术语进入正文前，必须判断是否属于作品世界自然表达；否则转译成符合当前文风的叙事表达。
- 新增正文自然度与项目匹配度检查：开头、人物行动、对话、设定比例、段落节奏、情绪/关系/局势变化和结尾压力都要按当前项目画像检查。
- 新增读者侧复读检查：读者读完应主要记住人物、冲突、画面、选择和变化，而不是字段、编号、权限、阶段、流程或检测。

现有小说实例无需迁移目录。建议将新版 `AGENTS.md`、`Claude.md` 和章节龙骨模板中的新增“内容执行标准”“内容上下文胶囊”“正文纯净检查”规则同步到正在创作的小说实例。
