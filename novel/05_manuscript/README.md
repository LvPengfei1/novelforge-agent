# 正文目录

本目录存放小说正文草稿和成稿。

建议命名：

```text
ch001.md
ch002.md
ch003.md
```

每章文件建议包含：

- 章节标题
- 正文
- 章末变更记录

章末变更记录用于提醒后续同步更新 llm-wiki。

章节正文写完后，必须同步更新对应章节龙骨：

```text
novel/03_plot/chapters/ch001-spine.md
novel/03_plot/chapters/ch002-spine.md
```

没有完成章节龙骨、`llm-wiki/wiki/outline.md` 总体大纲、时间线、人物状态、关系状态、伏笔账本和矛盾标记同步，不视为该章真正完成。
