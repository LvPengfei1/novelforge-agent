# 第四章 第一课

五月二十号。收录后的第一天。

GSC更新了数据。昨天4个UV，前天3个。今天截止中午——0。

按这个速度，一个月不到一百个访客。而"json formatter"这个关键词每天在Google上有十几万次搜索。我排在第47页，分到的流量约等于零。

前世我会觉得收录了就算"有点起色"，然后继续傻等。等了两个月，流量还是个位数。

今生我知道——收录只是第一步。真正的战场在排名。排名靠的是SEO。

我打开浏览器，搜索"哥飞社群"。

前世我是九月份才知道这个名字的。当时在一个出海论坛上看到有人推荐，说"做出海不进哥飞社群等于裸奔"。我进去的时候已经晚了——几百个帖子，最早的从2022年开始，我没耐心从头看。挑了几个热门的扫了一眼，觉得"也不过如此"，然后就潜水了。

那个"也不过如此"的判断，前世花了我一万多块钱和四个月的弯路才纠正过来。

——

社群入口是一个飞书链接。点进去，页面很简陋——一段介绍文字，一个付费二维码，199块一年。

199块。

前世我犹豫了三天才交这个钱。不是贵——是觉得"一个社群能教我什么"。

今生我扫了码，三秒钟。

付款成功。跳转到一个飞书文档库。

然后我愣住了。

不是被骗了——是信息量大到不知道从哪开始。文档库里有十几个文件夹：SEO基础、关键词研究、内容策略、外链建设、变现经验、工具推荐、案例复盘……每个文件夹下面十几个文档，每个文档几千字。光"SEO基础"这个文件夹就有四十多个帖子。

前世我进来的时候这些东西都在，我一个都没认真看。

现在我坐在电脑前，点开了"新手必读"文件夹里的第一个文档。

标题是四个字：《TDK先行》。

作者是周叔衡。

——

TDK。Title，Description，Keywords。标题，描述，关键词。

我以前以为这三个东西就是随便写写——反正Google会自动判断你的页面内容，对吧。

错。

周叔衡在帖子里写得很直接："你的Title Tag是Google看到你的第一件事。不是你的UI设计，不是你的代码质量，是你的标题。标题没写对，Google不知道你的页面在说什么，用户搜不到你。你的网站做得再漂亮也是零。"

然后他举了个例子。假设你做了一个JSON格式化工具，你的标题写的是"JSON Pretty Print - Online JSON Formatter and Beautifier"——看起来没问题，对吧？关键词都有了。

"但用户搜索的时候不会搜这些。"周叔衡写道。"用户搜的是json formatter online、json beautifier、json validator、pretty print json。你的标题应该精确匹配用户搜索的词，而不是你自己觉得好听的名字。"

我盯着屏幕。

因为我的标题就是"JSON Pretty Print - Online JSON Formatter and Beautifier"。

一个字不差。

帖子继续往下。Description不是给你看的——是给Google搜索结果页看的。用户在Google上搜东西，看到的第一行是你的Title，下面两行是你的Description。Description写得不清楚，用户不会点。用户不点，Google会觉得你的页面不够好，排名就会降。

Keywords标签Google已经不看了，但你的页面里必须有明确的关键词布局——H1标签里有关键词，H2里有相关词，正文里自然出现，不要堆砌。

我花了半个小时读完这篇帖子。又花了半个小时把里面的概念在脑子里过了一遍。

然后打开了自己的网站，看了看源代码。

Title：`JSON Pretty Print - Online JSON Formatter and Beautifier`。太长了，关键词没精确匹配，"Pretty Print"不是用户的搜索词。

Description：`A free online tool to format, beautify, and validate your JSON data.`太笼统了，没告诉用户这工具能解决什么问题，也没包含核心关键词。

H1：`JSON Pretty Print`。只有一个，跟Title一样模糊。

没有H2。没有FAQ。没有内链。

什么都没有。

前世我做站的时候觉得这些无所谓——工具好用就行了。结果Google根本不知道我的站是干嘛的，当然不给排名。第47页不是Google看不起我，是我没告诉Google我是谁。

——

打开ChatGPT。

"我有一个JSON格式化工具站，域名jsonprettyprint.com。帮我重写TDK。要求：Title精确匹配'json formatter'搜索词，Description突出核心功能和用户场景，同时生成一个FAQ板块回答常见的JSON相关问题。"

五秒钟。

新的Title：`JSON Formatter - Free Online JSON Beautifier & Validator`

新的Description：`Format, validate, and beautify your JSON data instantly. Free online JSON formatter with syntax highlighting and error detection. No signup required.`

FAQ板块：七个常见问题——"什么是JSON格式化？""怎么验证JSON是否有效？""JSON和JSONL有什么区别？"——每个问题都是有人搜的词。

我把这些改完，又按帖子的建议调整了H1和H2。H1只留一个，包含核心关键词。H2分出几个子功能：格式化、验证、压缩。每个H2下面简短说明。

整个优化过程从下午两点到五点。三个小时。

前世我会在这种时候觉得已经做完了，去刷视频等结果。

今生我知道——改完只是开始，Google还得重新爬你的页面才能看到变化。

打开GSC，点了"请求编入索引"。

又是一个等待。

但这次的感觉不一样。上次等收录的时候，我不知道自己在等什么——像考试交了卷但不知道答案对不对。这次我知道自己改了什么、为什么改、理论上应该有什么效果。

不是为了安慰自己。是真的知道。

——

手机震了一下。

大学室友微信群。

赵岩发了一张照片。新工位，新工牌，一家中型互联网公司。配文："新公司第一天。"

照片里的赵岩笑得很正式，背景是开放式办公区，桌上摆着一杯星巴克。

室友甲："牛啊岩哥！涨薪了吧？"

赵岩回了个得意的表情。

室友乙："陆远呢？你也跳了？"

我看到这条消息的时候，手指停在屏幕上。三秒。

然后打了四个字："在做网站。"

赵岩秒回："做什么网站？"

我："一个JSON工具站。上线了。"

赵岩的回复来得很快，快到我觉得他一直在盯着群：

"又是那个AI写的？你自己写的代码有几行？用AI写的也叫网站？"

后面跟着一个笑哭的表情。

室友甲："AI能写网站了？"

赵岩："就是ChatGPT自动生成的，改改就能用。跟玩似的。"

我没回。

不是生气。生气是前世的事。前世我听到这种话会难受好几天，觉得别人说得对，用AI不算本事。然后我会怀疑自己，放慢节奏，打开招聘网站看两眼"有没有合适的"。

今生我把手机放下了。

不是不在乎——是在乎的方向不一样了。赵岩觉得用AI写代码不算本事，这个判断前世我也做过。我花了六个月才想明白一件事：用户不在乎你的网站是手写代码还是AI生成的。用户在乎的是这工具好不好用。市场不在乎你的代码怎么来的。市场在乎你能不能解决问题。

——

重新打开电脑，看了一眼GSC。

重新索引的请求还在处理中。

明天再说。

我又点开哥飞社群的文档库，把"SEO基础"文件夹里的第二个帖子加入了书签。标题是《关键词研究：找到用户在搜什么》。

先看完了再说。

种树。别急。
