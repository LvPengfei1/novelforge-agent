## 正文纯净检查

- [ ] 正文文件只包含章节标题和正文
- [ ] 章末变更记录、同步检查、修改原因和审查记录未写入正文文件

- [ ] 工程层术语已检查；不属于作品世界自然表达的词语已转译为符合当前文风的叙事表达
- [ ] 读者侧复读通过：读者主要记住人物、冲突、画面、选择和变化，而不是字段、编号、流程、同步或检测

## 正文自然度与项目匹配度检查

- [ ] 标题符合当前小说项目和读者预期
- [ ] 开头有画面、行动或冲突，不是解释性摘要
- [ ] 人物在行动和对话中暴露态度，不用作者说明替代戏剧表现
- [ ] 对话符合人物身份、关系、情绪和信息差
- [ ] 没有直接解释情绪；关键情绪已通过动作、环境、对白、停顿或物件呈现
- [ ] 没有替读者总结意义或连续升华；必要时结尾停在画面
- [ ] 人物保留合理瑕疵、偏心、反复或自相矛盾，不是永远正确稳定的功能人
- [ ] 对白没有全部高效推进剧情，保留符合场景的人味、停顿、跑题、沉默或答非所问
- [ ] 生活细节来自当前场景，能增加真实感，没有随机堆砌
- [ ] 已完整阅读相关场面，确认叙述没有替人物解释、替读者归纳或用整齐收束掩盖场内变化；未用固定词表代替判断
- [ ] 设定、系统、证据或规则没有压过人物戏
- [ ] 段落和句式没有过分整齐平滑
- [ ] 本章有情绪变化、关系变化或局势变化
- [ ] 结尾形成继续读下一章的压力
- [ ] 已按内容执行标准派生本项目类型检查项，并完成检查
