# llm-wiki 常用查询提示

## 写作前查询

```text
请根据 `llm-wiki/wiki/book-spine.md`、`llm-wiki/wiki/outline.md` 和 `novel/03_plot/chapters/` 中当前/相邻章节龙骨，汇总【章节编号】所在章节组的功能、主线推进、支线咬合、必须承接的状态和本章不应提前揭示的内容。不要写正文。
```

```text
请在写【章节编号/场景名称】前生成临时“内容执行标准”。先读取当前小说项目的 `novel/00_project/brief.md`、`llm-wiki/wiki/book-spine.md`、`llm-wiki/wiki/outline.md`、当前章节龙骨、`character-states.md`、`relationship-states.md` 和 `foreshadowing-ledger.md`；只提取本次写作需要的类型题材、目标读者、文风基准、核心看点、禁用写法、章节功能、人物状态、核心冲突和本章阅读感。不要写正文。
```

```text
请根据当前资料生成【章节编号/场景名称】的“内容上下文胶囊”。胶囊只包含已发生剧情、本章开场状态、出场人物状态、人物动机、本章核心冲突、本章必须推进、本章结尾变化和项目文风；不要放入同步检查表、文件路径、发布记录、内部阶段编号、质量检测表、agent 操作说明或工程日志。
```

```text
请根据当前 llm-wiki，生成【章节编号】的章节龙骨草案。必须包含章节功能、开章状态、本章目标、核心推进、结尾变化、后续约束和待回收问题。不要写正文。
```

```text
请根据当前 wiki，汇总与【章节/场景名称】相关的人物、地点、组织、规则、伏笔和未解决冲突。只列已确立事实，并标出 wiki 缺失、矛盾或需要证据回查的条目。
```

```text
请检查【设定/人物/规则/研究结论】的证据等级：已确立、来源依据、推断待确认或废弃旧版。列出依据文件、相关章节和需要用户确认的内容；不得把推断待确认写成已确立事实。
```

```text
【章节/场景】涉及现实行业、历史、法律、医学、技术或平台规则。请先补充写前研究，优先读取 raw/ 和已摄入 wiki；资料不足时再查找当前可靠来源。输出关键结论、来源路径/链接、证据等级和写作限制，不写正文。
```

```text
请查询【人物名】的当前状态、核心动机、关系变化、已发生关键事件和禁止违背的写法。
```

```text
请查询【地点名】的功能、氛围、相关人物、已发生事件和当前限制。
```

## 连续性检查

```text
请检查【章节编号】的章节龙骨是否与 book-spine、timeline、character-states、relationship-states、foreshadowing-ledger 和 contradiction-flags 一致。列出矛盾、缺失同步项和建议修正。
```

```text
请检查 `llm-wiki/wiki/outline.md` 是否准确串联当前章节组：章节组功能、主线推进、支线状态和后续规划是否与 `book-spine.md`、`novel/03_plot/chapters/` 当前/相邻章节龙骨、`timeline.md`、`foreshadowing-ledger.md` 一致。列出需要修正的条目。
```

```text
请检查【章节/场景名称】涉及的人物状态、时间线、地点、道具、信息差和伏笔是否存在矛盾。输出冲突条目、相关 wiki 页面、可能需要回查的 raw/novel 位置和建议处理方式。
```

```text
请列出当前所有未回收伏笔，按与【当前章节】的相关度排序，并说明哪些不能提前揭示。
```

```text
【章节编号/章节正文】初稿已完成。请依据 `AIGC_DETECTION_PRINCIPLES.md` 执行原创性与文本质量检查，列出问题位置和影响，修改正文并复查。
```

```text
【章节编号/章节正文】初稿已完成。请执行正文自然度与项目匹配度检查：标题是否符合当前小说项目和读者预期，开头是否有画面和冲突，人物是否在行动中暴露态度，对话是否像人在说话，设定/系统/证据/规则是否压过人物戏，段落是否过于整齐平滑，本章是否有情绪、关系或局势变化，结尾是否有继续读下一章的压力。再根据当前项目画像派生类型检查项，不要用固定题材标准审查所有小说。
```

```text
请检查【章节编号/章节正文】是否被工程化上下文污染。重点扫描阶段、锚点、接口、后台、控制台、同步、检测、节点、权限、流程、编号等词语；判断它们是否是作品世界内自然存在、人物能说出口、读者能读顺的表达。不是则转译为符合当前文风、人物身份和场景语境的叙事表达。
```

```text
请对【章节编号/章节正文】做读者侧复读检查：如果读者主要记住的是人物、冲突、画面、选择和变化，则通过；如果读者主要记住的是字段、编号、权限、阶段、流程、同步或检测，请列出需要补戏、转译或重写的位置。
```

## 摄入后审查

```text
请根据【章节正文或摘要】更新对应章节龙骨，并按章节龙骨模板和项目规则原则列出必须更新、无需更新和需要用户确认的关联文件；无需更新的项目请说明原因。
```

```text
请根据【章节正文或摘要】判断是否需要更新 `llm-wiki/wiki/outline.md`：如果本章改变章节组功能、阶段推进、支线咬合或后续规划，请给出应追加或修订的总体大纲条目，并维护到对应章节龙骨链接。
```

```text
请根据【章节正文或摘要】执行节点缺口检查：列出本章新增或实质改变的人物、地点、组织、规则、物品、重要场景和伏笔；判断哪些达到建卡门槛；给出需要新建或更新的 wiki 节点页路径。正文原文不要进入 wiki。
```

```text
请列出本次摄入后新增或更新的 wiki 页面，并标注可能与旧设定冲突的条目。
```

```text
请对【本次修改内容/文件路径】执行关联文件同步检查：判断哪些文件依赖本次修改的事实、状态、进度、链接或摘要；列出必须更新、无需更新和需要用户确认的文件，并说明依据。
```

```text
请找出同名、近义或可能重复的人物、地点、组织、规则、物品页面，给出合并建议，但不要直接合并。
```
