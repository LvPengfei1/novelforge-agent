# 术语表（Glossary）

本页收录小说中出现的专业术语，确保全文用法一致。按领域分类，每个术语限1-2句说明。

---

## 一、出海建站核心术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| 出海 | Going Overseas | 将产品和服务面向海外市场，赚取美元收入 | 指主角重生后选择的创业方向 |
| 出海建站 | Overseas Website Building | 面向海外用户建设网站，通过广告或订阅赚取美元 | 小说核心主线，主角的创业路径 |
| 独立站 | Independent Site | 不依赖大型平台（如亚马逊、淘宝）、拥有独立域名的网站 | 主角建设的每个海外网站都是独立站 |
| 独立开发者 | Indie Hacker / Solo Developer | 不依赖公司团队、独立完成产品开发并盈利的人 | 主角的自我定位和身份 |
| MVP | Minimum Viable Product | 最小可行产品，只保留核心功能以最快验证需求 | 主角验证新想法时的标准做法 |
| PMF | Product-Market Fit | 产品市场匹配，产品真正满足用户需求的那个节点 | 主角追求的关键里程碑 |
| 养网站防老 | Nurture Sites for Retirement | 哥飞社群核心理念：像种果树一样持续经营网站，获得长期被动收入 | 主角信奉的长期主义哲学 |
| 种树理论 | Tree Planting Theory | 一次种树、年年收获；做网站如种果树，前期投入后期持续产出 | 主角用来解释坚持做站的心态 |
| 新词新站 | New Keyword New Site | 发现新兴搜索词后24小时内快速上线网站，抢占红利期 | 主角的重生优势之一：提前预知热门新词 |

## 二、SEO 术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| SEO | Search Engine Optimization | 搜索引擎优化，通过优化网站内容和结构获取自然搜索流量 | 主角每天投入时间最多的技能 |
| SEM | Search Engine Marketing | 搜索引擎营销，包含SEO和付费搜索广告 | 偶尔提及，与SEO互补 |
| SERP | Search Engine Results Page | 搜索引擎结果页面，用户搜索后看到的页面列表 | 主角关注自己的排名在SERP中的位置 |
| KD | Keyword Difficulty | 关键词难度，数值越高竞争越大、越难获得排名 | 主角选词时核心参考指标，偏好低KD词 |
| KGR | Keyword Golden Ratio | 关键词黄金比例（搜索量÷谷歌收录结果数<0.25），用于发现低竞争高流量词 | 主角挖掘蓝海词的方法论之一 |
| UV | Unique Visitor | 独立访客数，衡量有多少不同的人访问了网站 | 主角跟踪的每日核心指标 |
| PV | Page View | 页面浏览量，用户每次打开一个页面计一次 | 与UV配合衡量网站粘性 |
| CTR | Click-Through Rate | 点击率，搜索结果中用户点击的比例 | 主角优化TDK后关注的提升指标 |
| RPM | Revenue Per Mille | 每千次页面展示的广告收入 | 衡量AdSense变现效率的核心指标 |
| ECPM | Effective Cost Per Mille | 有效千次展示成本/收入，综合考虑所有广告收入的指标 | 剧情中AdSense危机的衡量单位（下降70-90%） |
| TDK | Title / Description / Keywords | 页面三要素：标题、描述、关键词，SEO优化的基础 | 主角每上线一个网站必做的第一步优化 |
| 内链 | Internal Link | 网站内部页面之间互相链接 | 主角用于提升网站结构和页面权重的手段 |
| 外链 | Backlink / External Link | 其他网站指向自己网站的链接，相当于投票 | SEO排名的核心因素，主角持续建设外链 |
| 反链 | Inbound Link | 外链的同义说法，指从外部网站指向本站的链接 | 与外链混用，小说中不刻意区分 |
| E-E-A-T | Experience-Expertise-Authority-Trust | Google评估内容质量的框架：经验、专业性、权威性、信任度 | 2025-2026年Google算法核心，主角必须适应 |
| Helpful Content | Helpful Content Update | Google有用内容更新，惩罚低质量AI生成内容 | 触发主角调整内容策略的剧情事件 |
| 长尾词 | Long-tail Keyword | 搜索量小但竞争也低的细分关键词，多个长尾词可汇聚可观流量 | 主角新站起步阶段的主要流量来源 |
| 种子词 | Seed Keyword | 关键词研究的起点词，用于扩展出更多相关词 | 主角用Semrush等工具从种子词扩展词表 |
| 词根 | Root Keyword | 关键词的核心部分，如"calculator"是"mortgage calculator"的词根 | 用于理解关键词结构和批量生成页面 |
| 蹭词 | Piggyback Keyword | 利用已有热门词的搜索流量，做相关内容获取排名 | 主角快速获取流量的策略之一 |
| 截流 | Traffic Interception | 针对竞争对手已有的搜索词，做更好的内容抢夺其流量 | 主角分析竞品后采取的进攻策略 |

## 三、技术术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| SSR | Server-Side Rendering | 服务端渲染，页面在服务器生成HTML后发送给浏览器 | Next.js默认模式，主角建站的技术选型 |
| SSG | Static Site Generation | 静态站点生成，构建时预先生成HTML文件，访问速度极快 | 主角对内容站采用的渲染策略 |
| CSR | Client-Side Rendering | 客户端渲染，页面在浏览器端通过JavaScript生成 | 对SEO不友好，主角尽量避免 |
| CDN | Content Delivery Network | 内容分发网络，将静态资源缓存在全球节点，加速访问 | 通过Cloudflare或Vercel自动获得 |
| DNS | Domain Name System | 域名系统，将域名解析为服务器IP地址 | 主角绑定域名时配置DNS记录 |
| 响应式 | Responsive Design | 网页自适应不同屏幕尺寸（手机、平板、桌面） | 海外用户移动端占比高，主角必须适配 |
| PWA | Progressive Web App | 渐进式Web应用，网站可像App一样安装到手机桌面 | 偶尔提及的高级优化方向 |
| API | Application Programming Interface | 应用程序接口，不同软件之间通信的标准方式 | 主角调用AI模型、支付平台等都通过API |
| Webhook | Webhook | 事件驱动的回调接口，当特定事件发生时自动推送数据 | 用于支付通知、自动化流程等场景 |

## 四、变现术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| AdSense | Google AdSense | Google广告联盟，网站主展示广告按展示和点击获得收入 | 主角初期主要收入来源，后期因ECPM下降需多元化 |
| SaaS | Software as a Service | 软件即服务，用户按月付费使用在线软件工具 | 主角进阶方向，从广告站升级为订阅制SaaS |
| MRR | Monthly Recurring Revenue | 月经常性收入，订阅制产品的核心财务指标 | 主角从AdSense向SaaS转型后追踪的收入指标 |
| Affiliate | Affiliate Marketing | 联盟营销，推荐他人产品并获得佣金 | 主角网站的辅助收入来源之一 |
| Stripe | Stripe | 全球在线支付平台，支持信用卡和订阅付款 | 主角SaaS产品的首选支付渠道 |
| PayPal | PayPal | 全球在线支付平台，覆盖面广，部分国家必备 | 作为备选支付方式出现 |
| 转化率 | Conversion Rate | 访客完成目标动作（如付费、注册）的比例 | 主角优化落地页时重点关注的指标 |
| 留存率 | Retention Rate | 用户在一定时间后仍继续使用产品的比例 | 衡量SaaS产品健康度的核心指标 |
| Churn Rate | Churn Rate | 流失率，订阅用户每月取消付费的比例 | 与留存率互补，主角监控的SaaS关键指标 |

## 五、AI 编程术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| 用嘴编程 | Programming by Mouth | 用自然语言描述需求让AI生成代码，无需手动编写 | 主角的重生金手指核心能力 |
| Prompt Engineering | Prompt Engineering | 提示词工程，设计精确的提示词以获得高质量AI输出 | 主角重生前积累的核心技能 |
| Token | Token | AI模型处理文本的最小单位，也是计费单位 | 影响API调用成本和上下文长度 |
| 上下文窗口 | Context Window | AI模型一次能处理的最大文本长度 | 超出窗口的信息会被截断，影响生成长文 |
| AI Agent | AI Agent | AI智能体，能自主规划、调用工具并执行多步骤任务 | 主角进阶后用Agent自动化建站流程 |
| Copilot | AI Copilot | AI辅助编程工具，在编辑器中实时补全和建议代码 | 指代Cursor、Claude Code等AI编程工具 |
| RAG | Retrieval-Augmented Generation | 检索增强生成，先检索相关知识再让AI生成回答 | 用于构建智能客服或知识库问答功能 |

## 六、社群 / 行业术语

| 术语 | 英文 | 含义 | 在小说中的用法 |
|------|------|------|----------------|
| 站群 | Site Network | 一个人或团队运营多个网站，通过规模效应提高总收入 | 主角长期目标：从单站扩展到站群 |
| 矩阵 | Matrix Strategy | 多个网站形成协同网络，互相引流、共享资源 | 主角规模化阶段的运营策略 |
| 哥飞社群 | Gefei Community | 国内知名的SEO出海付费社群，强调"养网站防老" | 主角重生前加入的社群，重生后重新加入 |
| Product Hunt | Product Hunt | 全球新产品发布平台，获得初期流量和外链的重要渠道 | 主角每个新产品都会在此发布 |
| Indie Hacker | Indie Hacker | 独立开发者，靠自己的产品盈利而不依赖投资人 | 主角的身份认同和社区归属 |
