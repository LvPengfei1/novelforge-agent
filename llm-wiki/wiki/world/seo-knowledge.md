## 一、SEO核心概念

### Google搜索排名机制

Google排名由200+因素共同决定，核心8要素按优先级：

| 优先级 | 因素 | 关键要点 |
|--------|------|----------|
| 最高 | 优质内容 | 解决用户真实问题、独特见解、深度足够、持续更新 |
| 极高 | 反向链接 | 质量远大于数量；权威站点链接最值钱；来源多样化 |
| 高 | 技术SEO | 网站速度、移动端适配、可抓取性、bug修复 |
| 高 | 关键词优化 | 标题含核心词、自然分布、避免堆砌、长尾词补充 |
| 中高 | 用户体验 | 布局清晰、导航合理、少弹窗、有价值补充内容 |
| 中 | 结构化数据 | Schema.org标记、产品/评价/活动信息、可能获得特殊展示位 |
| 中低 | 社交信号 | 方便分享、鼓励互动、内容质量的间接证明 |
| 中低 | 品牌信号 | 品牌知名度、在线口碑、品牌词搜索量 |

核心原则：**Google不是对手，是合作伙伴——一起给用户最好的搜索体验。**

### TDK优化

TDK是页面SEO三要素，直接影响搜索展示和点击率：

- **Title**：包含主关键词，50-60字符，关键词尽量靠前
- **Description**：吸引人的描述，150-160字符，包含关键词
- **Keywords**：主要关键词（meta keywords现在权重很低但仍有参考意义）

配套标签：Open Graph标签（og:title、og:description、og:image）用于社交分享展示。

### 内容结构（H1-H6）

- H1是"第二个标题"，每页只用一个，含核心关键词
- H2-H3用于分节，嵌入相关关键词
- 清晰的层级结构帮助Google理解内容主题
- Google首页内容平均约1400字，但质量永远高于字数

### 内链外链策略

**内链：**
- 内部链接多指向某页面，说明该页面重要
- 从权威页面（如首页）链过来效果更好
- 合理的内链结构有助于主题分类（筒仓结构）

**外链：**
- 链接域名数量比单域名链接数量更重要（10个不同网站的链接 > 1个网站的10个链接）
- 内容中的链接 > 侧边栏/页脚链接
- 锚文本要自然分布，过度优化会被盯上
- 链接增长要稳定，突然暴增会被怀疑作弊
- 买垃圾链接会被惩罚

### Sitemap和robots.txt

- **robots.txt**：告诉搜索引擎哪些页面可以抓取，指向sitemap位置
- **sitemap.xml**：XML格式的站点地图，列出所有页面URL、更新频率和优先级
- 两者配合帮助搜索引擎快速发现和收录新内容

## 二、关键词策略

### 新词新站——24小时黄金窗口

当新技术/新事件出现时，相关搜索词会突然飙升。此时：

1. 立刻注册相关域名
2. 用AI快速生成内容站
3. 提交搜索引擎收录
4. 在24小时内抢占排名窗口

**案例**：gemini3.com抢注后给YouWare引流，专业玩家开始追新词。蹭到新词就是一波大流量。

### KGR公式（Keyword Golden Ratio）

KGR = (Google标题含该词的结果数) / (月搜索量)

当KGR < 0.25时，该词属于低竞争高搜索量的黄金词，新站也有机会排名。

### 长尾关键词

- 搜索量小但意图明确，转化率高
- 新站应从长尾词切入，避免与大站正面竞争
- 积累足够长尾词排名后，网站整体权重提升

### 蹭词玩法

核心思路：追热门新词，给自己品牌站引流。

操作路径：
1. 监控Google Trends飙升词
2. 发现新需求立刻建站或用已有站承接
3. 流量导入自己的品牌站或联盟营销链接
4. 避免依赖单一变现渠道（订阅/广告/联盟可组合）

### 截流策略

**截别人的流：**
- 抢注竞品品牌词相关域名
- 用SEO抢占竞品品牌词排名
- 投放竞品品牌词的竞价广告（CPC往往较低，流量精准）

**防止被截流：**
- 不在全是竞争者的地方提前公布产品
- 确保搜索自己的品牌词能排第一位
- 自己投自己的品牌词提升权重

**案例**：小排老师的Raphael产品，盗版站流量一度超过正版。

### GSC出词数据反向新增内页

操作步骤：
1. 在Google Search Console后台查看"效果"中的搜索词
2. 发现有展示和点击但未专门布局的词
3. 针对该词新增内页承接
4. 对于高展示低点击的词：检查排名位置，若排名尚可则优化TDK匹配搜索意图

### 词根找需求方法

基于特定词根扩展需求关键词。常用词根表：

| 类别 | 词根示例 |
|------|----------|
| 工具类 | Translator, Generator, Converter, Calculator, Editor, Downloader |
| 创建类 | Maker, Creator, Builder, Designer, Constructor |
| 分析类 | Analyzer, Evaluator, Checker, Detector, Comparator, Verifier |
| 管理类 | Manager, Organizer, Planner, Tracker, Scheduler, Monitor |
| 其他 | Online, Free, Best, Alternative, VS, Review, Tutorial |

词找词的四条路径：
1. **Google Trends相关查询**：发现飙升词和新需求
2. **Google相关搜索**：页面底部的相关搜索词
3. **搜索下拉词**：输入过程中的自动补全建议
4. **Semrush/SimilarWeb**：直接查询关键词搜索量、趋势和KD

## 三、Google算法变化（2023-2025）

### E-E-A-T框架

Google质量评估的核心标准（从E-A-T升级为E-E-A-T，新增"经验"维度）：

| 维度 | 含义 | 对出海站的要求 |
|------|------|----------------|
| Experience（经验） | 作者是否有第一手经验 | 展示真实使用场景、截图、案例 |
| Expertise（专业性） | 作者是否是领域专家 | 展示专业背景、资质证明 |
| Authoritativeness（权威性） | 网站和作者是否被认可 | 获得权威外链、被引用 |
| Trustworthiness（信任度） | 信息是否可信 | 完整联系方式、隐私政策、HTTPS |

健康、财务等敏感领域（YMYL内容）E-E-A-T要求极高。

### AI内容检测与惩罚

- Google不禁止AI内容，但惩罚低质量AI批量生成内容
- 关键判断标准：内容是否真正帮助用户（Helpful Content）
- 纯AI生成的垃圾站会被识别并降权
- 结合AI效率与人工审核是可持续策略

### Helpful Content Update

- Google定期更新，专门打击为搜索引擎而非用户创作的内容
- 被打击后恢复困难，可能需要数月
- 核心要求：内容要有人读、有人用、有人愿意分享

### Core Updates的影响

- 每年数次大更新，排名可能大幅波动
- 被打击后的恢复策略：检查内容质量、提升E-E-A-T、增加原创价值
- 每次更新都是行业洗牌的机会

## 五、对小说的剧情价值

### 可写成技术博弈场景的SEO操作

| 场景 | 张力来源 | 适用情节 |
|------|----------|----------|
| 新词狙击赛跑 | 时间压力、对手竞争 | 主角发现新需求后与时间赛跑建站 |
| 算法更新被打击 | 生存危机、转型压力 | 站群一夜崩塌，需从头再来 |
| 截流攻防 | 商业道德与利益冲突 | 抢注竞品域名或防止被截 |
| GSC数据洞察 | 逆向思维的成就感 | 从数据中发现被忽视的金矿词 |
| 外链建设博弈 | 人脉与资源 | 高质量外链获取的艰难过程 |

### 新词狙击完整流程

1. **发现**：通过Google Trends/社区/新闻捕捉新需求
2. **分析**：用Semrush确认搜索量和KD，判断窗口期
3. **决策**：选择域名→确定内容策略→选定变现方式
4. **建站**：AI生成内容+TDK优化+结构化数据
5. **上线**：部署到Vercel→绑定域名→提交GSC
6. **排名**：等待收录→监控排名→根据数据调整
7. **变现**：广告/订阅/联盟营销/给品牌站引流

### 算法更新打击后的恢复路径

可作为小说转折点的恢复流程：

1. 确认被打击范围（全站/部分页面/特定关键词）
2. 分析打击原因（内容质量/外链问题/技术问题）
3. 制定恢复计划（内容改版/清理外链/提升E-E-A-T）
4. 执行并等待下次更新验证
5. 恢复期间寻找新流量渠道（社交媒体/直接流量/付费流量）
